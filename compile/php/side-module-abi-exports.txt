# Dockerfile adds it). Lines starting with "#" and blank lines are ignored.
#
# Computed statically (2026-09-23) rather than found one smoke test at a
# time: for each side module, every env/GOT import that isn't already a
# wasm export of the core, a JS library function of the loader, or
# provided by the module itself (including its own EM_JS functions). That
# covers code paths the smoke tests don't reach, at the cost of also
# exporting functions a module may never call. Every name was checked to
# be defined in Emscripten's PIC system libraries (libc, compiler-rt,
# libsockets), since an export the link can't find fails the whole build.
# Not listed: getpid, select, usleep, popen and pclose, which the core
# wraps (-Wl,--wrap); side modules get the wrapped versions through the
# wasmImports aliases in the Dockerfile's php.js patches instead.
